Wet Bulb Globe Temperature (WBGT) Status

The WBGT locations are not actual locations of the WBGT sensors, but are instead estimates of the actual locations. They will still provide a good reference for WBGT status.
Code White 29.9°C and below: 60mins work, 15mins rest
Code Green 30.0°C to 30.9°C: 45mins work, 15mins rest
Code Yellow 31.0°C to 31.9°C: 30mins work, 15mins rest
Code Red 32.0°C to 32.9°C: 30mins work, 30mins rest
Code Black 33.0°C to 34.9°C: 15mins work, 30mins rest
Cut-off 35.0°C and above: No Strenuous Training
